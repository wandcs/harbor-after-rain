| P7 传输集成 | 实际 HTTP+WebSocket，临时端口、自建自关；慢客户端与发送/事件/输入上限 | 同源页面与 `/ws` 可用；公共/本人状态同边界，单慢连接独立处置，无计时器、连接或历史泄漏 |
| P8 浏览器 | 实际原表现层、键鼠/触控入口，同机双会话进行移动、交火、换弹、暂停恢复和退出 | 作为开发自动化证据，观察校正、射击编号、快照与事件，无运行错误；不冒充双设备验收 |

## 本人状态与显示边界

本人保存/恢复共用字段定义，包含位置/速度/接地/蹲姿/眼高/跳跃冷却、视角/后坐/举枪、全部库存槽的弹药与各冷却/换弹/散布/射击数、随机状态、生命/阶段/射击编号、受击弹簧及偏移、步态/落地/震动/延迟投掷/自动切枪等历史变量。规则时间、已确认输入及碰撞样本与权威快照同边界；派生的武器参数、数学对象和对象引用重建，不传递游戏或材质实例。

远端真人与机器人只按公共快照采样显示。存活姿态发送可由共用计算重建的姿态配方，不默认发送骨骼矩阵；倒地姿态的必要局部变换作为非命中尸体显示数据。客户端和服务器历史查询使用同一插值与姿态重建函数，事件只产生独立表现。

证据写入 `artifacts/online-s2/`。S1 工作区在修改前以已有源文件指纹和快照为起点保留。最终记录分别说明实现、自动化验证、体验验收、集成与发布状态。

## 实际实现与字段依据

| 数据 | 实现与恢复方式 |
| --- | --- |
| 本人完整预测状态 | `src/sim/actor-state.js` 集中保存位置、速度、接地、蹲姿、眼高、移动与跳跃状态、视角、后坐、举枪、库存各槽全部动态武器字段、随机状态、生命/射击编号、受击弹簧/偏移、步态、落地与延迟动作；用同一函数恢复，武器定义和接触查询重建 |
| 权威边界 | 公共与本人状态在同一 `snapshotSeq` 组合发送；本人包含已执行或作废的 `ackSeq` 和实际沿用输入。比分、生命、阶段与时间仅由 `CombatMatch` 修改 |
| 输入与重放 | 共同使用 `sim/input.js` 的生命/阶段/新鲜度及边沿规则，固定 60 Hz。预测保存带权威时间的碰撞样本，重放不使用显示位置、不播放反馈；新射击按生命与射击序号去重 |
| 远端姿态 | 公共姿态包含实际算法更新前的必要状态、输入与步长，`pose-sample.js` 绝对重建；客户端插值与服务器回溯使用相同端点和权重。普通事件只产生独立特效，不修改远端命中骨骼 |
| 有限回溯 | 只接受该连接确实发送过的两个端点；查询时间受连接时间采样及 200/250 ms 上限约束。样本、阶段、生命或时间失效时整发只做一次当前查询，保留来源与原因；历史保护和当前生命保护均检查 |
| 生命周期与队列 | 暂停、3 秒倒计时和恢复由核心控制；中断消息只清本人输入。替换角色使用新身份，复活使用新生命；应用关闭释放房间、连接、历史和定时器；输入、重放、事件、发送字节和历史均有有限上限 |

S2 的单房间接纳只提供技术样例入口。真人可退出再加入，断线不恢复旧角色；最后真人离开销毁样例房间。完整大厅与结算产品流程仍属 S4。`ws@8.23.0` 通过锁文件固定，服务端构建附 Three.js 与 ws 许可；完整可发布依赖目录及运行演练仍属 S6。

## 修复及最终评审

- 补齐共用射击中的雷达计时，使预测和权威状态逐字段相同；新出生的零速度与落地状态明确初始化，首次射击起点为有限数。
- 页面忙碌后渲染可能先于排队快照执行：超过未来输入窗口时等待新样本，不发送越界输入，也不立刻把短暂调度差当作断线；持续缺快照才终止会话。
- 回溯保存每连接实际发过的有限样本集合，防止替换队列跳过的样本被当作可用；死亡/复活及保护状态在实际射线链路中验证。
- 成员更新只增删对应远端对象，保留本人的输入和显示实例；旧会话关闭回调不清理后来新建的会话。
- 相对 S1 指纹核对原文件的差异，新增协议、同步、服务及测试单独列入最终来源清单；没有顺带搬迁或格式化未涉及模块。证据包含来源快照、构建、摘要、日志与截图，最终压缩包带 SHA-256。
