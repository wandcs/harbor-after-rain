# S4 实现与测试方案

日期：2026-11-14。用户明确要求开始 S4；继续此前“实机暂缓，先实现与自动化”的安排，不将此视为 S2/S3 体验门槛已通过，也不进入 S5 或发布。

目标：交付列表、创建、密码、4v4/5v5/8v8、双玩法、完整武器、配装、更替、断线、暂停与结算返回列表。按房间接纳、共用规则、客户端流程三块实现并分别验证；最后累计回归、检查、构建、真实浏览器、受影响网络与离线复验。

| 覆盖 → 责任 | 既有证据与缺口 → 处理 | 独立预期 |
| --- | --- | --- |
| 房间接纳 → 服务器 | 原 app 生命周期仅覆盖样例；新增 S4-R1 | 三种人数代表变体，自动编号、密码不下发，错误密码/满员/结束拒绝且保留连接；最后空位并发只有一人成功；真人均衡分队、替换为新角色，比分保留 |
| 房间隔离与释放 → 服务器 | 复用暂停/队列；新增 S4-R2 | 暂停期间加入/离开，重复恢复不延长、新暂停取消倒计时；创建者退出不影响其他人；断线无席位；最后真人退出及结束释放；列表真人数正确，结果一次且连接仍能创建新房间 |
| 武器及离场投掷物 → 共用规则 | 枪械状态已有；新增 S4-M1，复用真实 Actor 输入 | 四种主武器、手枪、刀与手雷走实际动作；伤害、冷却、归属不转交替补；出生区即时配装、区外复活生效；退出清理未生效操作 |
| 双玩法与计时 → 共用规则 | 复用 RelayState 原边界、S2 到时/胜利；新增 S4-M2 | 实际核心占领/争夺/遮挡/保护/轮换、暂停冻结、三分钟先结束、50 分提前、平局、结果一次；不靠直接切目标阶段代替动作 |
| 协议、输入边沿 → 协议/客户端 | 扩展现有用例，不另建套件 | create/list/join/loadout 消息范围；sw/altPressed 一次消费，旧生命/阶段不复活 |
| 列表/结果会话 → 客户端 | 原会话只有自动加入；新增 S4-C1 | 接纳失败留列表，退出/结算重置输入、事件与快照；同一连接再次入场，新房间低序号正常接受；断线提示明确 |
| 完整武器重放 → 客户端 | 原预测只实测 M4；新增 S4-C2 | 实际武器切换、刀/投掷准备与重放不重复副作用，状态可恢复；权威伤害仍只由服务端执行 |
| 产品流程 → 集成 | 新增独立 S4-I1 浏览器入口；两玩法必要变体 | 真实点击创建/密码加入/列表、键鼠切枪射击/配装、暂停恢复、结算返回并复用连接；保留原交火/触控与离线回归 |

数量预算：新增 6 条永久 Node 用例 + 1 个浏览器场景（两玩法变体）；只在明确失败或新增合同缺口时修订。三人数变体只用于服务器接纳，双玩法只用于核心与连接处，不展开全层笛卡尔积。稳定编号可独立选择；自建服务/页面、可控时钟、有限等待，finally 释放；未知选择失败。新增子目录前检查发现范围，当前递归发现已覆盖上述位置。

集成审查补强：S4-I1 仅在团队竞技变体内增加一次真实投掷，验证切换、准备、权威投出、客户端可见投掷物、爆炸与移除。Node 已覆盖计算与重放，这里只补新增的跨端展示连接处，不再展开武器或玩法组合。

关键预期来自产品规则与独立数字；低层验证计算，服务器验证调用及所有权，浏览器验证操作连接处。真实网络工具需显式创建测试房间，不能隐含依赖样例自动开局。旧协议语义被替换时提高协议版本，同步修改所有实际客户端/脚本；不保留第二套样例生产入口。

证据保存在 `artifacts/online-s4/20261114/`：开工来源、分块结果、首次失败、最终源码差异、构建标识及受影响回归。每条具体场景的状态和检查点随代码落地，执行后另记通过/失败与剩余项；本方案不表示已经通过。

## 2026-11-15：统一规则配置补强

依据产品与技术方案的统一规则合同，收口在线、离线的 180 秒、50 分与常规机器人难度；移除分数和难度选项，清理旧存储，保留其他设置。武器和中继计算已有共用实现，本次沿用；不调整传输或性能参数。

| 覆盖与责任 | 复用入口 | 补强及独立预期 |
| --- | --- | --- |
| 共用规则 | `S4-M2` 与既有 `game-state` 用例 | 配置与产品字面值一致且不可变，权威默认 50 分和常规机器人；保留两玩法到时、暂停与提前结算断言 |
| 离线入口与迁移 | `menu-match-check.mjs` | 从旧 `goal=100/diff=hell` 存储进入，确认旧字段和选择入口移除，其他设置保留；实际开局 180 秒、50 分和常规机器人，两玩法提前胜利按 50 分检查 |
| 在线入口 | `S4-I1` 两玩法 | 同样从旧存储进入，检查固定规则展示、迁移与服务器目标一致，继续原产品流程和资源清理 |
| 离线实际操作 | `s1-browser-check.mjs --file` | 最终单 HTML 断网移动、射击、换弹、暂停恢复和两玩法重开，无 HTTP 与 WebSocket |
| 交付与回归 | 原累计测试、`check`、`build`、`s2-launch-check.mjs` | 新模块符合边界，原测试不退化，四份构建清单及打包入口一致 |

不新增永久用例；复用的浏览器场景和参数变体不加入 Node 用例数量。菜单用例先在旧构建复现失败，再验证修复。独立命令、构建来源和执行结果见[实现记录](s4-test-results.md#2026-11-15统一规则配置收口)。本轮证据在 `artifacts/shared-rules/20261115/`；真实设备、目标服务器与 O4 未通过项继续保留。
